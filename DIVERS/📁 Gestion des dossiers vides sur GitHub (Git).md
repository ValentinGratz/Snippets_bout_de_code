# 📁 Gestion des dossiers vides sur GitHub (Git)

## 🧭 Introduction

Git ne permet pas de versionner les dossiers vides.  
Un dossier sans fichier est simplement ignoré lors des commits.

Pour contourner cette limitation, on utilise un fichier “placeholder” afin de forcer la conservation du dossier dans le dépôt.
